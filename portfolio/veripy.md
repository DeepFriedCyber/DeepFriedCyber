# VeriPy

**Status:** Research prototype  
**Area:** Software assurance / verification tooling

## Research question

Can software be associated with verifiable behavioural or structural properties so that inconsistent modification becomes easier to detect?

## What I explored

VeriPy is a Python prototype combining:

- AST-based static analysis
- constrained execution
- behavioural validation
- deterministic verification/orchestration concepts
- CLI-based workflows
- pytest-based testing infrastructure

## My role

I originated the research question and directed LLM-assisted development and evaluation of the prototype.

## Important limitation

VeriPy is experimental software-assurance tooling. It is **not** a proof system for arbitrary program correctness, and its constrained execution should not be treated as a security-grade sandbox.

The implementation repository is currently private.
